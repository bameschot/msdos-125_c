MS-DOS 1.25 DEMO DISK  (720 KB)
================================

WELCOME!  This disk contains example BASIC programs,
documentation, and a full-screen text editor.

QUICK START
-----------
  DIR              list everything on this disk
  TYPE README.TXT  read this file
  TYPE OS.TXT      read the OS command reference
  TYPE BASIC.TXT   read the BASIC interpreter guide
  BASIC FIB.BAS    run a BASIC program
  EDIT README.TXT  open this file in the editor

BASIC PROGRAMS
--------------
  FIB.BAS       Fibonacci sequence
  GUESS.BAS     Number guessing game
  CALC.BAS      4-function calculator with memory
  TIMES.BAS     Multiplication tables
  HAMURABI.BAS  Govern ancient Sumeria (classic 1973 game)
  PRIMES.BAS    List prime numbers up to a given limit
  CONVERT.BAS   Unit converter (temperature, length, weight)
  LOAN.BAS      Monthly loan payment calculator
  STATS.BAS     Descriptive statistics (mean, min, max, stddev)
  QUIZ.BAS      Mental arithmetic quiz

HELP FILES
----------
  OS.TXT        OS command reference
  BASIC.TXT     BASIC interpreter language guide

EDITOR KEY REFERENCE
---------------------
  Ctrl+W  save          Ctrl+X  quit
  Ctrl+G  goto line     Arrows / Home / End / PgUp / PgDn

Type EXIT to leave MS-DOS and return to the host system.
